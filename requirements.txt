# Pinned to exact versions (2026-08-10), not >= ranges: unpinned deps let pip
# resolve a different exact version on every Colab rebuild, which shifted
# floating-point precision in face detection (insightface/onnxruntime) enough
# to change where the head-scale clamp's box landed run-to-run -- the same
# commit produced a clean render in one Colab instance and a visibly seamed
# one in the next, purely from this drift. Pinning does not fully eliminate
# variance (Colab's own preinstalled torch/CUDA base image is outside this
# file's control and can still shift between allocations), but it removes
# the largest controllable source of it.
numpy==2.3.4
Pillow==11.3.0
opencv-python-headless==4.10.0.84
PyYAML==6.0.2
tqdm==4.67.1
requests==2.32.3
# Colab setup forces HF_HUB_DISABLE_XET=1; do not install hf_xet for large downloads there.
# NOT tightly pinned (unlike the others in this file): GPU-verified
# 2026-08-10 that pinning this to an exact older version (0.25.2) broke
# ComfyUI's own import chain -- Colab's preinstalled transformers/gradio/
# diffusers need a much newer huggingface_hub than headswap_V2 itself does,
# and downgrading it for this package alone made `import transformers` fail
# with "cannot import name 'is_offline_mode' from 'huggingface_hub'". A
# floor of >=0.24.0 wasn't enough either -- on an environment where some
# earlier install had already left an old version in place, `pip install -r`
# doesn't touch an already-"satisfying" package, so the broken old version
# survived a plain reinstall. Floor raised to match what diffusers itself
# requires, so a fresh resolve can't land below the version ComfyUI needs.
huggingface_hub>=0.34.0
# Identity scoring (ArcFace) used by the Colab quality gate
insightface==0.7.3
# NOT listed here as a plain pin: resolving a plain onnxruntime pin alongside
# insightface==0.7.3 in the SAME `pip install -r` call makes pip's resolver
# backtrack to onnxruntime==1.19.2, which has no wheel for Python 3.13
# (Colab's base image moved to 3.13 on some allocations, unpredictably) and
# fails the whole install outright -- GPU-confirmed 2026 on a fresh Colab
# allocation. setup_colab.sh installs the wanted version (1.20.0, the oldest
# with a 3.13 wheel) SEPARATELY with --no-deps right after this file's
# install step, the same way it already force-reinstalls pillow below for an
# equivalent conflict -- so it never enters the same resolver pass. Bump the
# version in setup_colab.sh (not here) if a future Colab base image moves
# further.
# Jupyter/Colab already has a running asyncio loop; Comfy bootstrap needs this
nest_asyncio==1.6.0
pytest==8.3.3
